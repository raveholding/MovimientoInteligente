# Movimiento Inteligente · Nahuel Cornu

Sistema de gestión para entrenamiento personalizado: alumnos, planes de 1, 2 y 3 sesiones semanales,
modalidad presencial y virtual, agenda de lunes a viernes, programas de entrenamiento, cobros y control de acceso.

Es un único archivo `index.html`. Se abre directamente en el navegador, sin instalar nada.
Los datos se guardan en el navegador (localStorage); desde Ajustes se puede copiar un respaldo.

Los precios y alumnos que trae son de ejemplo: se cambian y se quitan desde Ajustes.
